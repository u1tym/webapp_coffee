# API設計作成（日本語）

> 元Cursorルールでの適用範囲: `specs/**/api-design.md` を編集するとき。エンドポイントの契約

見出しと本文は日本語で書くこと。

`specs/templates/api-design-template.md` に従うこと。

エンドポイントごとに、メソッド、パス、認証（要/不要）、要求、応答、エラーを書くこと。HTTP ステータスはここに書く。

テーブル定義と ER 図は書かないこと。列や関連は `db-design.md` を参照する。

画面レイアウトや部品配置は書かないこと（それらは `ui-design.md`）。Vue コンポーネント構成は `design.md`。

認証しない（`rules/14-security.md`）。共通節に「認証しない」と書き、各エンドポイントの認証は「不要」とする。401 / 403 は使わない。

要件に存在しないエンドポイントを追加しないこと。

ユーザが `db-design.md` を承認するまで、このファイルを作成しないこと。
ユーザがこのファイルを承認するまで、`tasks.md` を作成しないこと。

承認欄は履歴形式とする（日時・状態・変更概要。詳細は `CLAUDE.md`）。
