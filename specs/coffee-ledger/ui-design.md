# 珈琲台帳（coffee-ledger） UI設計

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

全画面の上端にヘッダ（左: ブランド名「珈琲台帳」、右: ナビ「飲む」「管理」）を置く（`rules/15-ui-style.md`）。画面幅による配置の切り替えはしない。

以下の「処理中」は、API の呼び出しを始めてから結果を反映し終えるまでを指す。処理中は、その画面の操作ボタンを無効にする。

## 画面一覧

| 画面ID | 画面名 | パス | 目的 |
|--------|--------|------|------|
| SCR-001 | 一般画面 | `/` | 飲用・支払の記録と取り消し（REQ-001〜006） |
| SCR-002 | 管理パスワード入力画面 | `/unlock` | 管理機能に入る前の管理パスワードの確認（REQ-007） |
| SCR-003 | 管理トップ画面 | `/admin` | 一杯単価、徴収状況、金庫収納、金庫操作、DB の整理（REQ-008〜011、REQ-022） |
| SCR-004 | 人の管理画面 | `/admin/people` | 人の登録・利用停止・表示順、記録の参照、未払いの修正（REQ-012〜016） |
| SCR-005 | 集計画面 | `/admin/summary` | 金額の推移の表示、金銭の動きの CSV 出力（REQ-017、REQ-023） |
| SCR-006 | 操作記録画面 | `/admin/operations` | 操作記録の表示（REQ-018） |

## 画面詳細

### SCR-001: 一般画面

コンテンツは全面型（`rules/15-ui-style.md`）。画面もコンテンツもスクロールさせない。

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| 上部バー（左） | 一杯単価 | 「一杯 100円」。未登録なら「単価未登録」（`.price.missing`） |
| 上部バー（右） | 現在日時 | `YYYY-MM-DD HH:mm:ss`（日本時間）。1 秒ごとに更新。`aria-live="polite"` |
| 上部バー | エラー | 失敗時のみ、小さなエラー表示（`.error.compact`） |
| 行一覧 | 人の行（利用中の人 × 表示順） | 2 列のグリッドに、表示順で左→右、次の行へと並べる（1 番目が左上、2 番目が右上）。行の高さを均等に縮め、全員を 1 画面に収める |
| 人の行 | 名前 | 太字。はみ出す場合は `…` で省略 |
| 人の行 | 未払いボタン | 未払い代金（`1,234円`）をラベルにする。押すと支払モーダルを開く。未払い代金が 0 なら無効 |
| 人の行 | 飲むボタン | 「飲む」。押すとすぐに飲用を記録する（確認なし）。一杯単価が未登録なら無効 |
| 人の行 | 最後の飲用日時 | 日付と時刻を 2 行（`YYYY-MM-DD` / `HH:mm`）で右揃え。取り消し済みなら取り消し線。飲用が無ければ「—」 |
| 人の行 | 取り消しボタン | ゴミ箱のアイコン（`aria-label`「取り消し」）。押すとすぐに最後の飲用を取り消す（確認なし）。最後の飲用が無い、または取り消し済みなら無効 |

**完了モーダル（飲用の記録後）**

| 領域 | 部品 | 説明 |
|------|------|------|
| 本文 | 文言 | 「毎度ありがとうございます」（大きな太字、中央揃え） |
| 本文 | カウントダウン | 文言の下に残り秒数を中央揃えで表示する。開いた時点で「5」、以後 1 秒ごとに 4、3、2、1 と減らす。`aria-live="polite"` |
| 操作 | OK ボタン | 主ボタン。押すとすぐにモーダルを閉じ、操作を受け付ける状態に戻る |

「1」を表示してから 1 秒後に、モーダルは自動で閉じ、操作を受け付ける状態に戻る。OK ボタンで閉じた場合は、カウントダウンをそこで止める。

モーダルを開いている間、行一覧のボタンはすべて無効にする。

**支払モーダル**

| 領域 | 部品 | 説明 |
|------|------|------|
| 見出し | 見出し | 「○○ の支払」 |
| 本文 | 未払い代金 | 「未払い 1,234円」 |
| フォーム | 金額 | ラベル「金額」。`[−] [金額（読み取り専用、右揃え）] [＋]` の並び。初期値は未払い代金の全額 |
| フォーム | −ボタン | REQ-005 の規則で 10 円減らす。未払い代金が 10 円未満、または金額が 10 円以下なら無効 |
| フォーム | ＋ボタン | REQ-005 の規則で 10 円増やす。金額が未払い代金に達していれば無効 |
| 操作 | 支払い確定ボタン | 主ボタン。金額が 1 円以上かつ未払い代金以下のときだけ有効。成功したらモーダルを閉じる |
| 操作 | 閉じるボタン | 通常ボタン。記録せずにモーダルを閉じる |
| 直近の支払 | 直近の支払 | 直近の支払が取り消し済みでないときだけ表示。「直近の支払 YYYY-MM-DD HH:mm 1,234円」（小さめの文字） |
| 直近の支払 | 取り消しボタン | ゴミ箱のアイコン（`aria-label`「直近の支払を取り消す」）。押すとすぐに取り消す（確認なし）。取り消し後もモーダルは開いたままにし、未払い代金・金額・直近の支払を読み直す |

モーダルは背景をクリックしても閉じない。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一杯単価は「単価未登録」、行一覧は空で表示し、読み込み後に置き換える |
| 読込中 | 専用の表示はしない（初期のまま） |
| 空 | 行一覧の位置に「利用中の人はいません。」（`.muted`） |
| エラー | 上部バーにエラーメッセージ。読み込み・記録・取り消し・支払モーダルを開く処理の失敗はすべてここに出す（支払モーダルを開く処理が失敗した場合、モーダルは開かない）。支払の確定が失敗した場合、モーダルは開いたままにする |

### SCR-003: 管理トップ画面

コンテンツはページ型。パネルを上から「一杯単価」「徴収状況」「金庫操作」「DB の整理」の順に積む。

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| 見出し | ページ見出し | 「管理」 |
| 見出し | 下位画面へのリンク | 横並びで「人の管理」「集計」「操作記録」「一般へ」 |
| 見出し | エラー | 失敗時のみ（`.error`） |
| 一杯単価パネル | 見出し | 「一杯単価」 |
| 一杯単価パネル | 金額 | ラベル「金額」。数値の入力欄（1 以上の整数）。初期値は現在の一杯単価、未登録なら 100 |
| 一杯単価パネル | 保存ボタン | 主ボタン。1 以上の整数でなければ無効。確認なしで保存する |
| 徴収状況パネル | 見出し | 「徴収状況」 |
| 徴収状況パネル | 3 つの金額 | 「未徴収 ○円」「徴収済み ○円」「金庫 ○円」を 1 行ずつ |
| 徴収状況パネル | 金庫に収めるボタン | 主ボタン。徴収済みが 0 なら無効。押すと確認ダイアログ「徴収済み ○円 を金庫に収めます。よろしいですか？」を出し、同意したら実行する |
| 徴収状況パネル | 小見出し | 「金庫収納の履歴」 |
| 徴収状況パネル | 金庫収納の履歴 | 新しい順に「YYYY-MM-DD HH:mm · 1,234円」 |
| 金庫操作パネル | 見出し | 「金庫操作」 |
| 金庫操作パネル | 事由 | ラベル「事由」。文字の入力欄（200 文字まで） |
| 金庫操作パネル | 入金または出金 | 項目名「入金または出金」。ラジオボタン「入金」「出金」を横並び。初期値は入金 |
| 金庫操作パネル | 金額 | ラベル「金額」。数値の入力欄（1 以上の整数）。初期値は 1 |
| 金庫操作パネル | 事由の日付 | ラベル「事由の日付」。日付の入力欄。初期値は今日（日本時間） |
| 金庫操作パネル | 記録するボタン | 主ボタン。事由が空、金額が 1 以上の整数でない、出金で金額が金庫金額を超える、のいずれかなら無効。押すと確認ダイアログ「事由「…」で 入金（出金） ○円 を記録します。よろしいですか？」を出し、同意したら実行する。実行後も入力値は残す |
| DB の整理パネル | 見出し | 「DB の整理」 |
| DB の整理パネル | 説明 | 「不要な領域を回収し、統計情報を更新します。台帳のデータは変わりません。」（`.muted`） |
| DB の整理パネル | 整理するボタン | 主ボタン「整理する」。押すと確認ダイアログ「DB を整理します。よろしいですか？」を出し、同意したら実行する。実行中は「整理中…」と表示し、この画面の操作ボタンをすべて無効にする |
| DB の整理パネル | 結果 | 成功したときだけ、ボタンの下に「DB の整理が完了しました（所要 1.2 秒）。」。次に整理するボタンを押すまで表示する |

操作が成功したら、一杯単価・徴収状況・金庫収納の履歴を読み直す（DB の整理の後は読み直さない）。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 金額は 0 円、一杯単価の入力は 100、履歴は空で表示し、読み込み後に置き換える |
| 読込中 | 専用の表示はしない（初期のまま） |
| 空 | 金庫収納の履歴の位置に「金庫収納はまだありません。」（`.muted`） |
| エラー | 見出しの下にエラーメッセージ。読み込みと各操作（DB の整理を含む）の失敗はすべてここに出す。DB の整理が失敗したときは結果を表示しない |

**部品配置**

| 領域 | 部品 | 説明 |

| 記録パネル | 未払いの修正 | 小パネル。見出し「未払いの修正」、「現在 ○円」、ラベル「新しい額」の数値の入力欄（0 以上の整数。初期値は現在の未払い代金）、ラベル「事由」の文字の入力欄（200 文字まで）、主ボタン「修正する」を縦に並べる |
| 記録パネル | 修正するボタン | 新しい額が 0 以上の整数でない、現在と同じ額、事由が空、のいずれかなら無効。押すと確認ダイアログ「○○ の未払いを ○円 から ○円 に修正します。事由「…」。よろしいですか？」を出し、同意したら実行する |
| 記録パネル | 飲用記録 | 小パネル。見出し「飲用記録」。新しい順に「YYYY-MM-DD HH:mm · 100円」。取り消し済みは取り消し線と「取消済み」のバッジ。操作ボタンは置かない |

| 空 | 飲用記録・支払記録の位置に「飲用記録はまだありません。」「支払記録はまだありません。」（`.muted`）。人が 0 人のときは人の一覧に何も表示しない |
| エラー | 見出しの下にエラーメッセージ。読み込みと各操作の失敗はすべてここに出す |

## 画面遷移

管理パスワードの入力済み状態は、管理機能の画面（SCR-003〜006）の間を移る間だけ保つ。SCR-001 へ移る、またはブラウザを再読み込みすると解ける。

| 画面 | 操作 | 遷移先 |
|------|------|--------|
| 全画面（ヘッダ） | ブランド名「珈琲台帳」 / 「飲む」 | SCR-001 |
| 全画面（ヘッダ） | 「管理」 | 入力済みなら SCR-003、未入力なら SCR-002（入場先: SCR-003） |
| 全画面 | 管理機能の画面（SCR-003〜006）のパスを直接開く | 入力済みならその画面、未入力なら SCR-002（入場先: 開こうとした画面） |
